## ✨ About the Project

The **Range Rover Replica Website** is a front-end project created to replicate the look and feel of a high-end automotive brand website.
The goal of this project is to practice **UI layout, responsiveness, typography, and visual hierarchy** using core web technologies.

This project is purely for **educational and portfolio purposes**.

---

## 🚀 Features

* Fully **responsive design**
* Clean, modern UI inspired by luxury automotive websites
* Structured and readable HTML
* Custom styling using CSS
* Smooth layout flow and spacing
* Beginner-friendly codebase

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3**
* No frameworks, no libraries — pure front-end fundamentals

## ▶️ How to Run Locally

1. Clone the repository

   ```bash
   git clone https://github.com/Yuvrajsinghko/Range-Rover-Replica-Website.git
   ```

2. Navigate into the project folder

   ```bash
   cd Range-Rover-Replica-Website
   ```

3. Open `index.html` in your browser
   or use **Live Server** in VS Code for a better experience.
